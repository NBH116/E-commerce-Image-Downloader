  1. 01

    打开商品详情

    首页、搜索、店铺页不会出现按钮。只有确认是详情 URL 才注入悬浮「获取图片」。

  2. 02

    扫图，不是扫图标

    读取 img、srcset、懒加载属性和背景图，丢掉 logo、占位图和小于 100×100 的碎片。

  3. 03

    勾选，下成 PNG

    新标签网格预览。原图是 jpg / webp 也会转 PNG。下载带进度，结束有成功/失败统计。

安装工序单

开发者模式加载本地目录，无需商店。

  1. 打开 Chrome，地址栏输入 chrome://extensions。
  2. 打开右上角「开发者模式」。
  3. 「加载已解压的扩展程序」，选择本仓库的 extension 文件夹。
  4. 进入淘宝 / 京东 / 拼多多商品详情页，右下角应出现「获取图片」。
  5. 在图库页勾选后点「下载选中」，PNG 进入浏览器默认下载目录。

本工具面向商家整理自己的商品图。请遵守各平台规则与版权要求，不要抓取无权使用的图片。
